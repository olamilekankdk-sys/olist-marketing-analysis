SQL portfolio case study

Olist Ecommerce Analysis

A reproducible analysis of the public Olist Brazilian ecommerce dataset, focused on revenue, customers, payments, fulfilment and review performance.

~100korders analysed
9related tables
6business questions

What this project shows

The project demonstrates relational joins, aggregation, date logic, common table expressions and business-focused interpretation. Each question is supported by a documented SQL query.

Evidence and limitations

The delivery and review analysis is a descriptive state-level comparison. It does not calculate a statistical correlation coefficient and does not claim causation.
